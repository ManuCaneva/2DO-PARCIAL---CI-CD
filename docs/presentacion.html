Version Control

Git + GitHub · Feature-branch strategy · Branch protection

⑂
Feature Branches
Each change is developed in a specific branch (feature/*) and integrated via Pull Request.
⛊
Branch Protection
main protected: requires PR with at least 1 approval. No direct pushes.
⯈
Pull Requests
Each PR triggers the full pipeline on Semaphore. Only merge to main triggers deploy.
⟐
Commit Convention
Commits include a tag ([2DOP-01]) that Trello uses for automatic tracking.

Pipeline CI/CD

Semaphore CI · 3 sequential blocks · Automated validation

Core Business Flow
Contract Audit + Traceability
→
Code Quality Inspection
SonarCloud Quality Gate
→
Docker Build Validation
nginx:alpine image
→
Deploy to Render
Only from main via PR
1
Contract Audit (SDD)
Executes run_contract_test.sh — if it fails, the pipeline is aborted and feedback is activated via Trello + Telegram + Gemini AI.
2
SonarCloud Quality Gate
Static analysis: bugs, code smells, duplications. The pipeline only continues if it passes the Quality Gate.
3
Docker Build + Deploy
Builds the Docker image with Nginx Alpine. When merged to main, Render deploys automatically.

Spec-Driven Development + AI

Automated contract · Gemini AI · Generated fix-plan

📋
The Contract
The rendered body of index.html must be exactly "MINOLI". No extra spaces or additional text.
⚙️
Automated Test
run_contract_test.sh extracts the body text, cleans HTML tags, and compares against the contract.
🤖
Gemini AI Analysis
If the contract is broken, ask_gemini.sh sends the error + code + requirements to Gemini 2.5 Flash.
📄
Fix Plan
Gemini produces fix-plan.md with: Detected Error, Root Cause, Steps to Fix, and Final Verification.
